Reconstruction of the GEO Indices
The proposed neural network is a deep residual feedforward network designed to predict three physical parameters from a 7-dimensional input vector. The input first passes through a positional encoding layer (posEncND), which enriches the input representation with multi-frequency information, enabling the network to capture variations across multiple scales. A fully connected projection layer then maps the encoded input into a 128-dimensional latent space. The core of the network consists of 4 identical residual blocks, each containing two fully connected layers of width 128 with tanh activation, along with a skip connection that adds the block's output to its input — a mechanism that facilitates deep network training by mitigating the vanishing gradient problem. Finally, a linear fully connected layer reduces the representation to the 3 output parameters, followed by a tanh activation layer that constrains the predictions to the interval (−1, +1), suitable for normalized outputs or physically bounded quantities with a defined sign.
